# Leznard

Leznard is an early-stage software project being developed around business operations, with a planned desktop experience and a dedicated professional workflow for accountants.

## Project Direction

The current repository represents the foundation stage. The product direction includes a desktop application for day-to-day users and a more specialised accountant-facing workspace. Detailed workflows, implementation choices and integrations are still being developed.

## Current Status

**Foundation / early development.** This repository should not yet be treated as a finished or production-ready accounting system. Features, calculations, data integrity, security and reporting must be implemented and tested before real business use.

## Development

The technology stack and setup instructions will be documented here as the implementation is stabilised. Do not assume the project is ready to run in production based on the presence of source files alone.

## Repository Hygiene

Keep local virtual environments, environment files, generated databases, build outputs and IDE settings out of version control. Use the repository's `.gitignore` rules and never commit passwords, API keys or signing credentials.
